# ⚡ X-AR (Xray Auto Restart Panel)

A lightweight CLI tool for managing and auto-restarting Xray via systemd.

> ⚠️ This project is currently designed specifically for use with **X-UI by MHsanaii**.  
🔗 https://github.com/MHSanaei/3x-ui

---

## 🚀 Features
- Start / Stop / Restart Xray service
- Auto-restart interval control
- Simple CLI panel
- systemd integration
- Uninstall option

---

## 🚀 Install

```bash
git clone https://github.com/yourname/x-ar.git
cd x-ar
chmod +x install.sh
sudo bash install.sh

▶️ Run
x-ar

⚙️ Config

/opt/x-ar/x-ar.conf

INTERVAL=1800
ENABLE_LOGS=true
